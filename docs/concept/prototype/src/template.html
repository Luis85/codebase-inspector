About this bundle

Includes Three.js r140 (0.140.0), an older MIT-licensed runtime verified against its upstream Git blob. It is pinned for this offline demo, not recommended as the production dependency. Camera gestures use a small custom controller; this is not OrbitControls.

This page is not an installed Obsidian plugin. Import only the documented snapshot format. There are no network requests, external fonts, analyzers, or source-code loaders.

SVG icons: Font Awesome Free by Fonticons, Inc. (fontawesome.com), licensed CC BY 4.0 (creativecommons.org/licenses/by/4.0/). Icons are combined into a local symbol sprite. No font files are included.
